# 金融科技发展奖 · 数据导入指南

## 为什么要有这一层

这张图上关于「行业成熟到什么程度」的判断，大部分是经验判断。**金融科技发展奖是其中唯一可核查的硬证据**：有年份、有完成单位、有项目名称、有奖项等级，且官方公示可查。

用途有三个：

1. 节点角上的 🏆 徽章，是行业成熟度的客观佐证
2. 单位视图下，某单位有获奖项目映射到某节点时可作为「已建成」的证据并附来源
3. **年度 × 领域热力图**，看这些年行业投入热点的迁移轨迹——汇报讲趋势时比什么都直观

**两条铁律**（已写进界面）：
- 获奖代表该机构在此方向具备一定成熟度
- **未获奖不代表该机构没有建设**。本工具只把奖项当加分证据，绝不做反向推断

## 当前数据的状态

`data/awards.js` 里已经录了打底数据，但**需要复核和补全**：

| 部分 | 可信度 | 说明 |
|---|---|---|
| `TT.awardStats` 各年度总数与等级分布 | 较高 | 多来源交叉印证 |
| `TT.awards` 具体项目条目 | **需复核** | 生成时人民银行官网被网络出口策略拦截，完整名单 PDF 未能直接获取 |

每个条目带 `verified` 字段标注核实程度：

- `official` —— 来自官方名单，可信
- `snippet` —— 来自检索结果的标题片段，较可信但需复核
- `summary` —— 来自二手报道的归纳，**必须复核**

界面上会如实显示每条的核实程度，不会把未核实的东西装成事实。

## 怎么补全

### 第一步：拿到官方名单

**中国人民银行官网** → 金融科技 → 金融科技发展奖获奖项目公示。

每年度的公示页会挂一个 PDF 附件，就是完整获奖名单，含：序号、项目名称、完成单位、主要完成人、获奖等级。

已知的公示页（供参考，年度更新后路径会变）：

- 2023 年度：`http://www.pbc.gov.cn/rmyh/105208/5481403/index.html`
- 2024 年度：`https://www.pbc.gov.cn/rmyh/105208/5878684/index.html`

### 第二步：整理成 CSV

在页面里点「奖项热力」→「导出奖项 CSV 模板」，得到的文件是 UTF-8 带 BOM 的，Excel 双击直接能开。列格式：

| 列名 | 说明 | 示例 |
|---|---|---|
| `year` | 评奖年度 | `2024` |
| `level` | 奖项等级 | `一等奖` |
| `org` | 完成单位（第一完成单位即可） | `中国建设银行` |
| `project` | 项目名称，照抄官方名单 | `主机核心银行系统全面下移工程` |
| `mappedNodes` | 映射到的技术节点 ID，多个用 `\|` 分隔 | `T4023\|T4021\|T10024` |
| `source` | 来源说明 | `2024 年度金融科技发展奖获奖项目名单` |
| `url` | 来源链接 | `https://www.pbc.gov.cn/...` |
| `verified` | 核实程度 | `official` |

### 第三步：映射到技术节点

这一步需要人工判断，也是这份数据最有价值的地方。建议：

1. 从项目名称判断它主要解决什么技术问题
2. 在页面里搜相关技术，找到对应的节点 ID（详情面板标题下方显示 `T7023` 这样的 ID）
3. **一个项目通常映射 1–4 个节点**，映射太多会稀释信号
4. 拿不准就少映射，宁缺毋滥

映射示例：

| 项目名称 | 映射节点 |
|---|---|
| 金融行业云建设与应用实践 | `T9022` 私有云 IaaS、`T9023` 容器与 K8s、`T9024` 混合多云 |
| 基于业务建模的大型银行分布式核心系统建设 | `T4021` 分布式核心、`T4022` 分布式事务、`T9033` 单元化 |
| 金融行业千亿级大模型建设和应用 | `T8021` 大模型基础平台、`T8023` 领域模型微调、`T10011` GPU 算力池 |
| 大模型安全管理及应用评估能力体系建设 | `T12031` 模型风险管理、`T12032` AI 内容安全 |

### 第四步：写回 data/awards.js

按现有格式追加条目即可：

```js
{ year: 2024, level: '一等奖', org: '中国建设银行',
  project: '主机核心银行系统全面下移工程',
  mappedNodes: ['T4023', 'T4021', 'T10024'],
  source: '2024 年度金融科技发展奖获奖项目名单', verified: 'official',
  url: 'https://www.pbc.gov.cn/rmyh/105208/5878684/index.html' },
```

改完跑 `node tools/validate.mjs`，校验器会检查 `mappedNodes` 里的 ID 是否都存在。

### 同时更新年度统计

`TT.awardStats` 里补上该年度的总数与等级分布，热力图的基数才准：

```js
{ year: 2025, total: 000, levels: { 特等奖: 0, 一等奖: 0, 二等奖: 0, 三等奖: 0, 专项奖: 0 },
  source: '中国人民银行 2025 年度金融科技发展奖获奖项目公示', url: '...' },
```

## 建议的工作量

完整名单每年 200–300 项。全量录入不现实也没必要，建议分层：

- **必录**：特等奖 + 一等奖（每年约 20 项），信号最强
- **建议录**：银行业的二等奖（每年约 40–60 项）
- **可选**：与本行重点规划方向相关的三等奖
- **可跳过**：印钞造币、非银机构等与银行 IT 科技树无映射关系的项目

近三年（2022–2024）的一等奖录完，热力图就已经能看出趋势了。
