# 金融科技树 · Banking FinTech Tech Tree

一张《文明》风格的银行金融科技演进树，用于规划未来银行的技术路径。

**打开方式：双击 `techtree.html`**（Chrome / Edge 均可，无需安装任何东西、无需联网、无需起服务）。

---

## 它是什么

把银行科技的演进画成一张有向依赖图：**先有数据仓库才能有客户数据平台，先有 GPU 算力池和 MLOps 才能有大模型平台**。
横轴是六个时代，纵轴是 5A 企业级架构的五条线，节点之间的连线是真实的技术前置关系。

- **157 个技术节点 · 263 条依赖边**，其中 **75 条跨 5A 架构线**——跨线依赖正是规划中最容易踩坑的地方
- **三层颗粒度**：12 个领域（给行领导）／ 35 个能力（给条线领导）／ 157 项技术（给架构师）
- 聚合层按 **「主体 × 时代」** 切分，六个时代在任何粒度下都完整可见，演进故事不断代
- **依赖只在技术层定义一次**，上两层的连线与进度**全部自动推导**，不存在"改了细节但汇报图没同步"
- 默认视图是**世界金融科技基准**（行业整体成熟度），切换单位后才显示各家的建设状态

## 主要能力

| 能力 | 说明 |
|---|---|
| 三层下钻 | 顶栏切换粒度，或**双击大节点原地展开、双击技术节点收拢**；带 FLIP 过渡动画；面包屑与 Esc 随时返回 |
| 依赖溯源 | 悬停节点：上游祖先链亮**金色**，下游后继链亮**青色**，其余淡出 |
| 六种着色 | 技术成熟度 / 本单位建设状态 / 与行业基准的差距 / **信创自主可控** / 业务价值 / 金融科技发展奖 |
| 专题视图 | 打标签抽取独立子树：**AI 视图**、信创视图、风控视图、开放银行视图、实时化视图 |
| 规划路线图 | 选目标技术 → 自动反推最小依赖闭包 → 按年产能装箱分阶段 → 导出 Markdown |
| 奖项证据层 | 以人民银行金融科技发展奖作为行业成熟度的可核查佐证 + 年度领域热力图 |
| 多单位 | 每个单位一份档案文件，可与基准或彼此对比 |
| 演示模式 | 按时代逐幕点亮，用于向领导讲演进故事 |
| 维护模式 | 在页面里直接改，改完导出数据文件覆盖即可 |
| 双主题 | 深空科技风（暗色，汇报大屏）/ 银行专业风（**亮色**，截图进 PPT、打印） |
| 背景分区 | 泳道按 5A 色相着底色 + 左侧彩色轨道条；时代按彩虹色带 + 明度递进 + 罗马数字水印 |
| 冻结表头 | 时代与架构名固定在上方与左侧，随平移跟随、字号不随缩放变化 |
| 架构线筛选 | 点顶部 A1–A5 进度格 = 只看该架构线，可多选 |
| 维护模式 | 任何视图下点节点即可编辑基准字段；单位视图下另可编辑本单位状态 |

## 三件立刻要做的事

1. **填我行现状**：切到「我行」→ 逐个点节点选状态（或开维护模式批量填）→ 导出 → 覆盖 `data/orgs/my-bank.js`
2. **补全奖项名单**：见 `docs/奖项数据导入指南.md`，官方公示 PDF 是最准的来源
3. **按行内口径改节点**：`data/nodes.js` 里增删改，改完跑 `node tools/validate.mjs` 确认没结构错误

## 数据可信度声明

- **技术成熟度**判断属行业共识，可信度较高
- **行业普及度**刻意采用分档（普遍具备 / 多数在建 / 领先机构具备 / 个别试点 / 尚无落地）而**不给百分比**——银行内部建设进度多不公开披露，伪精确的百分比比不给数字更有害
- 每个节点带 `confidence` 置信度，低置信度在界面上标灰并提示「待核实」
- **金融科技发展奖**是目前最好的可核查证据源。生成时人民银行官网被网络策略拦截，具体条目部分来自二手报道，均标注核实程度，需与官方 PDF 复核
- **获奖代表有成熟度，未获奖不代表没建设**——本工具只把奖项当加分证据，不做反向推断
